Conversor de Unidades de Medida
Este é um programa simples em Python para conversão de unidades de medida, incluindo unidades de massa, tempo e volume.

Funcionalidades
- Conversão de unidades de massa (gramas, quilos, libras, onças, miligramas).
- Conversão de unidades de tempo (segundos, minutos, horas, dias).
- Conversão de unidades de volume (mililitros, litros, galões).

Como executar
Baixe o código do repositório.
Abra o terminal ou prompt de comando e navegue até o diretório onde o arquivo `converter-unidades-medidas.py` foi baixado.
Execute o script com o comando: python converter-unidades-medidas.py
